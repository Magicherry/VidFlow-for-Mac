## Windows 有、macOS 有差异

- 多连接下载组件：`FileDownloader` 同样分块，但进度按块更新。
- 文件名输入框的变量插入：SwiftUI 取不到光标位置，统一追加到末尾。
- 取消任务后残留的分片文件与 Windows 一样不会自动删除。
